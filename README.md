# Calgary Dash

3-day weather (°F) for Calgary or Banff (tap to switch) and a CAD ⇄ USD converter, as an installable web app.

**Open:** https://johnvv999.github.io/calgary-dash/

**Install on iPhone:** open the link in Safari → tap Share → *Add to Home Screen* → Add.

Data: [Open-Meteo](https://open-meteo.com/) (weather), [Frankfurter](https://frankfurter.dev/) / ECB (exchange rate, looked up once per day).
